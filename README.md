# ドパガキ我慢ゲーム（Ver.1）

「待てば増える……とは限らない」ポイント確定タイミングを見極める、スマホ向け心理戦ミニゲーム。

タイトル → ゲーム本編 → 結果画面 → リトライ までの一通りの流れを実装済み。

## 起動方法

```bash
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザ（スマホ幅推奨・DevToolsのデバイスモードでもOK）で開く。

本番ビルドは `npm run build`（`dist/` に出力）、`npm run preview` でビルド後の確認ができる。

## 実装済みの内容（仕様書との対応）

- タイトル画面 → ゲーム画面 → 結果画面 → リトライの一連の画面遷移
- ポイントは加算方式の「基準値（amplitude）」に対する比率で上昇し、暴落系だけ現在値への倍率で減少する設計。
  進行度に応じて基準値が緩やかに増え、かつポイントが基準値に近づくほど伸びが鈍る（headroom）ため、
  数値が指数関数的に暴走せず、ランク上限（4,000pt+）付近で頭打ち感が出るようにしてある
- 序盤は上昇のみ→中盤で必ず初めての暴落→その後はランダムイベントの組み合わせ→終盤は大勝負、という
  シナリオ構成（仕様書14章）
- イベント種別：通常上昇 / 急上昇 / 暴落 / じわじわ下落 / 停滞 / 暴落からの復活 / フェイクピーク /
  急激なインフレ / 期間限定フラットボーナス / フェイクボーナス（カウントダウン→当たり/はずれ/逆に下落）/
  謎のカウントダウン（何も起きない緊張演出）
- ランダムな煽りメッセージ（仕様書11章の文言）をゲーム中に随時表示
- 最高到達ポイントを常時表示（暴落後も表示し続けて後悔を強化）
- 最大90秒（プレイヤーには非表示）で自動確定＋ボーナス倍率
- ドパガキランク（0〜4,000pt+の6段階）とドパガキ度（%）を結果画面に表示
- ランクごとにランダム表示される結果コメント、欲張り度コメント（最高到達との差分）
- 自己ベストの localStorage 保存・結果画面での表示・更新演出
- 結果カード（スクリーンショット向けデザイン）
- 結果シェア：Web Share API 対応端末はネイティブ共有、非対応時はX/LINEへのシェアリンク＋
  テキストコピーボタンにフォールバック
- スマホ最優先（最大幅430px中央寄せ、片手操作、縦画面前提）のオリジナルデザイン

## 動作確認

Playwright（Chromiumヘッドレス、390x844のスマホ相当ビューポート）でタイトル→プレイ→暴落演出→
結果表示→リトライの一連の流れ、コンソールエラー無し、localStorageの自己ベスト永続化を確認済み。
また、ポイント推移ロジックを200回シミュレーションし、暴走せず全ランク帯に自然に分布することを確認済み。

## 今後調整しやすい箇所

ゲームバランス・文言はすべて `src/config/` にまとめてあり、ロジック本体を触らずに調整できる。

- `src/config/gameConfig.ts`
  - `startPoint` / `maxDurationMs` / `autoEndBonusMultiplier`：開始ポイント・制限時間・自動確定ボーナス
  - `amplitudeCap`：ポイントの伸びの基準となる上限（大きくすると全体的に高得点が出やすくなる）
  - `midPhaseWeights`：中盤〜終盤のイベント抽選重み（暴落を増やす/上昇を増やす、など調整可能）
  - `events`：各イベントの変化量レンジ（比率）
  - `dopagakiPercentCap` 等：ドパガキ度の算出パラメータ
- `src/config/rankConfig.ts`：ランクの境界値・名称（`RANKS` 配列を編集するだけ）
- `src/config/messages.ts`：煽り文言・暴落/急上昇/フェイクボーナス等のメッセージ・結果コメント・
  シェア文面のテンプレート（すべて配列やテンプレート関数なので追加・差し替えが容易）
- `src/engine/eventTemplates.ts`：イベントの挙動そのものを変えたい場合（新しいイベント種別の追加など）
- `src/engine/timeline.ts`：序盤/中盤/終盤のシナリオ構成ロジック
